# CRYPTOZ 2.7 — guided research terminal

Use the existing terminal, provider gateway and private release workflow. A second frontend would duplicate selection, trust rules and streaming. A chart widget swap would lose local drawings and chart tools without fixing data ownership. Choose progressive disclosure: a persisted Basic/Pro switch with the same active symbol, interval and canvas; isolated pure feature modules behind it.

1. Chart first. Cursor is an exclusive candle-open time in UTC epoch seconds; gateway/direct respect their venue and interval, including aligned Coinbase 4h folding. Start with the existing latest batch. Prefetch near the left edge on user gestures, allow explicit Older candles and Latest, keep local drawing anchors and the existing viewport, report retries/end/cap, and never treat a temporary outage as historical exhaustion. Bound history to 4,000 bars per open view; no unbounded memory. Keep latest quote, stream reconciliation and historical pagination independent; batch high-frequency callbacks and avoid rewriting studies on every scroll/tick.
2. Basic shows essential chart navigation, one-click starter setups, plain English candle/market and risk steps. Pro exposes studies, drawing, exports, comparison, order book and advanced controls. Both modes offer short meanings, help, study and simulated practice. Existing left navigation and storage remain.
3. Add an automatically plotted catalog of 10–20 studies covering trend, momentum, volatility and volume, with intentional warm-up and limited simultaneous panes. Include selectable presets and automatically calculated recent price levels.
4. Paper practice uses only virtual money, fresh same-venue spot quotes, visible cost assumptions, long-only simulated fills, a local ledger, and clear open/closed P&L. No wallet, keys, leverage, transaction or exchange mutation.
5. Study POV explains real closed OHLCV, uncertainty and conditional scenarios; never infer an exchange-specific future or fake an AI result. Analyst research must have attributable dated primary evidence, disclosed coverage and a common timeframe, with no invented consensus or unsupported claims of historical accuracy. Keep editorial evidence separate from chart-derived observations.
6. Polish dark/light glass, typography and mobile interaction. Use bounded layered motion, prefers-reduced-motion and solid-material fallbacks. Avoid canvas particles and animated blur. Maintain primary information hierarchy.

Acceptance: regression tests, provider-backed recent-to-older history smoke on both venues, browser scroll/zoom/older navigation and same viewport, studies on current candle data, practice buy/sell and persistence, Basics/Pro mobile controls, keyboard use, full production checks and matching release packaging. No promises of universal markets, perfectly accurate predictions or production-scale load.
