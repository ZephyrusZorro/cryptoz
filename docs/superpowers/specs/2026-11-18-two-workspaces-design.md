# CRYPTOZ 3.1 — two workspaces, one data layer

The 3.0 archive is reference material; review code and dependencies before reuse. Do not execute bundled build files or copy unsupported claims. Options: fork wholesale (regresses navigation and validation), add all features to a single long screen (repeats the reported layout), or retain the tested data foundation and integrate isolated features into task-focused routes. Choose the third.

- Basic is a separate guided layout: a start-oriented Home, a market card explorer, a full-width readable price view with next steps, and one short task at a time. Pro is a dedicated research layout with a market monitor Home, dense searchable screener, chart workbench, compact selectable inspector, and stronger evidence details. Home remains the only mode switch; five primary destinations stay. Sections are routes or real panels with matching labels, not anchor links to distant content. Never keep a tall rail beside a dead chart area.
- Forecast: independently score supported horizons using only confirmed venue/pair candles and embargo; same-origin baseline, samples, scores, downloadable cases, immutable outcomes, stale/switch/retry handling. No invented scenario percentages, forecast confidence, or analyst hit rates. Active charts may annotate causal levels and historical evidence separately from predictions.
- Practice: real paper quotes stay separate from historical replay and backtest. A replay reveals one candle at a time. A rule decided at a close fills at a subsequent open with explicit costs. Any working orders must be scoped, nonnegative, and fail honestly if a fresh observation cannot settle. No real order adapters.
- Market insight feeds must use fixed public upstreams, validate values/timestamps, keep per-component source and errors, and tolerate region/rate restrictions. Grouped screener uses verified provider IDs and live/snapshot labels.
- Teach with self-contained exercises and answer reasoning. Analysts keep verifiable original sources; earned track record requires a defined comparable outcome and correct end timestamp, not today’s price. Retain previous workspace data and published source provenance.
- Acceptance: fixed layout across desktop/phone; real end-to-end checks for modes, inspector, news, archive jump/history, model, and practice; sources, tests, build, portable archive, private deployment smoke.
