# Beginner assistance and quality review

The user authorizes brainstorming, planning and implementation without repeated approval questions. Preserve the selected CRYPTOZ visual system and private Site audience. This is a focused extension of the existing software, not a replacement application.

## Approach

Considered: a separate beginner website; an AI advice chatbot; contextual guidance plus an integrated learning path. The third is the engineering choice: it reuses real tools and introduces no unsupported model advice or second navigation system. Existing stack and four compact left-rail groups remain.

## Product behavior

- Home exposes a small Start here action; Charts exposes Chart guide. Both open concise contextual explanations through the existing accessible dialog controller.
- Signals & guides gains internal Getting started / Signal readings / Glossary views. Getting started offers five practical tasks with browser-local, manually checked progress and direct navigation to real tools. No pop-up on first visit. Experienced users retain direct access to Signal readings.
- Searchable glossary covers venue, quote, candles, timeframe, EMA, RSI, MACD, ATR, spread, slippage, market cap, liquidity, stop and reward/risk. Distinguish historical conditions from predictions and static learning text from real observations. Link primary Coinbase/Binance educational references.
- Risk assistance explains units, account risk versus position size, fees and loss-at-stop assumptions. Clarify short calculations as scenarios, not spot-selling capability. Show an explicitly defined reward/risk convention and break-even win rate only when mathematically meaningful. Never recommend a coin, entry, target or risk percentage.
- Guard Use current price with actual observation freshness/staleness and explicit instrument identity. Entered manual levels remain usable. Edits invalidate old calculated results so they cannot be mistaken for the changed form.

## Quality review

Review all source boundaries and exercise core Home → search/chart → indicators/drawings/risk → comparison/learning → workspace and news/maps/appearance paths. Fix confirmed issues with regression tests. Prioritize stale identity/results, canceled requests, invalid financial inputs, storage errors, unavailable upstreams, small-screen overflow and keyboard recovery. Record discovered defects and limits; no zero-bug or all-device certification.

Learning/comparison own cancelable request lifetimes and snapshot identity. Provider catalogs arriving after a request must not silently relabel the displayed result. Route disposal cancels pending work. Learning help stays usable without provider availability.

## Acceptance

Passing regression suite, production build, dependency audit and live route checks; fresh review of the changes; actual desktop/phone dark/light interaction checks; private publication of exact pushed source/build; matching portable ZIP, screenshots and evidence report. Existing notes/drafts remain intact and no user research is injected during hosted checks.
