# CRYPTOZ 2.8 decision desk design

A shared workspace with Home-only mode preference keeps symbol, paper ledger and research separate. A separate Basic frontend would duplicate data validation and navigation, while making everything one Chart tab caused the existing clutter. Retain the validated provider gateway and compact left rail.

- Five primary destinations: Home, Markets, Charts, Practice, Learn. Home secondary: Overview, News, Analyst views. Markets: Explore, Maps, Watchlist/Alerts (existing stored workspace via utility). Charts: Chart, Compare. No links named Learn outside the dock. Old Learn/workspace hashes remain usable. Existing saved notes are exportable and preserved; remove chart note UI. New chart sidebar has chart reading, current technical setup and evidence.
- Home only Basic/Pro controls. Basic uses clearer words, visual and compact grouping, starter presets and short in-context explanations. Pro retains quantitative market table, depth, settings, extra studies, thresholds and manual axes/drawings. Mode persists and applies to layout/chart.
- Automatic tools use only eligible closed candles; recent range, confirmed swing trendline and Fibonacci from auditable anchors, event markers with brief setup/confirmation. Manual tools are explicit in Pro, stored drawings remain. Advanced indicators independent of forecast model.
- Historical model trains locally on confirmed venue/interval candles. Walk forward with embargo, compare to simple historical baseline, show actual sample/holdout/error and withhold a directional call unless the gate passes. Persist small browser-local issued-study/outcome ledger and settle when the exact future horizon closes. Support deep historical fetch on request; paced bounded pagination and explicit provider gaps/cap. No generated facts or accuracy guarantee.
- Market asset categories use verified identities and curated coverage, never ticker collision or fake allocations; performance groups use actual calculated metrics. Home shows live tape plus news and breadth, and standalone dated analyst source view discloses assumptions. No invented market-wide consensus.
- Practice page uses existing simulation/ledger with independent same-venue ticker and cancellation; never an exchange order. Provide position calculator on Practice; retain a light contextual connection from Charts only if needed.
- Test live providers, navigation/history/modes, indicator placements, ledger and historical model leakage/staleness, keyboard and responsive layout. Publish exact verified build with the same private audience.
