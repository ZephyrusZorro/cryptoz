# Adaptive forecast study

CRYPTOZ evaluates whether the same market’s close is strictly higher five candles after the latest confirmed close. A flat close is counted as “not higher” for scoring and is shown as flat in the ledger. The model uses the selected exchange, pair and interval. Every origin and target is a UTC candle close timestamp.

The browser fits regularized logistic regression to trailing log price moves, close position inside the candle, and changes in candle range. It refits at each historical origin using 160 to 780 past examples whose five-candle outcomes closed at least one candle before that origin. The baseline uses the same training observations and estimates the chance of a higher close as the historical up proportion with one pseudo-count for each outcome. The test evaluates both methods at the same UTC origins, spaced five candles apart. A missing candle ends the continuous sample and an active candle is excluded. [Hyndman and Athanasopoulos on rolling forecasting origins](https://otexts.com/fpp3/toolbox.html#time-series-cross-validation)

The results report the actual test dates, test forecasts, training examples, Brier error and direction accuracy. Brier error is the mean squared difference between the up probability and the observed outcome, either zero or one. Lower is better. Direction accuracy uses a 50% threshold on all tested forecasts. [National Weather Service technical attachment on the Brier score](https://repository.library.noaa.gov/view/noaa/33800/noaa_33800_DS1.pdf)

The model needs at least 50 and uses up to 120 historical forecast origins, with at least 8 examples of each outcome. CRYPTOZ issues a directional study when the model improves the average Brier error by at least 0.01, matches or beats the baseline’s accuracy, and improves Brier error in three of four chronological test blocks including the latest one. The latest estimate also needs to be at least 60% for either outcome and based on the latest expected closed candle. These are fixed screening rules. The test shows past performance on the available candles, while the local ledger records subsequent observed outcomes.

The ledger saves one issued study per close for the exchange, pair and interval. The issue timestamp, forecast probability and origin close stay fixed. A result settles only when data confirms the exact target candle for that market. Missing targets remain pending until the matching closed candle is available. The browser retains up to 32 entries per market and interval and 192 entries total. Secure browsers with the Web Locks API coordinate changes across tabs. [W3C Web Locks API](https://www.w3.org/TR/web-locks/)
